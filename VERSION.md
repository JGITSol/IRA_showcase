# Version History

## v1.0.0 (Current)

**Release Date:** 2023-07-15

### Features
- Initial working version of the Insurance Risk Predictor application
- Prediction of insurance charges based on user inputs
- Risk score calculation and visualization
- Database storage for prediction history
- Model insights with feature importance visualization
- Modern UI with responsive design
- Comparison of predictions with average charges
- Risk factor explanations

### Technical Details
- Built with Streamlit framework
- Plotly visualizations for interactive charts
- SQLite database for data persistence
- Scikit-learn based prediction model

## Version Numbering System

This project follows [Semantic Versioning](https://semver.org/) (SemVer):

- **MAJOR version (X.0.0)** - Incompatible API changes or significant redesigns
- **MINOR version (0.X.0)** - New functionality added in a backward compatible manner
- **PATCH version (0.0.X)** - Backward compatible bug fixes and minor improvements

Additional labels for pre-release and build metadata are available as extensions to the MAJOR.MINOR.PATCH format.
